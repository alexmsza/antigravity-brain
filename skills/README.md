# 🎯 Matriz Mestre de Skills do Antigravity

Este diretório cataloga todas as **Skills Especializadas** integradas ao Antigravity, organizadas por domínios de engenharia e ciência. Cada skill define heurísticas avançadas, scripts automatizados e regras de qualidade para guiar o par de desenvolvimento.

---

## 🗂️ Categorias de Skills

### 1. [Frontend, Design Systems & UI](frontend-and-ui.md)
- `frontend-builder`: Arquitetura de aplicações modernas React 19 e Next.js 15.
- `shadcn-ui`: Criação de componentes acessíveis com Radix UI, Tailwind v4 e Base UI.
- `tailwind`: Padrões e tokens CSS Tailwind v4, `@theme` e design tokens oklch.
- `design-system`: Governança de tokens, CVA variants e multi-brand theming.
- `react-patterns`: Otimização de re-renders, React Compiler, use() API e Server Components.
- `next-best-practices`: Route Handlers, Streaming SSR, imagens otimizadas e caching.
- `sousza-brand-design`: Diretrizes visuais canônicas da Sousza Consultoria.

### 2. [Backend, Banco de Dados & Infraestrutura](backend-and-databases.md)
- `db-enforcer`: Integridade estrutural para PostgreSQL, RLS zero-trust e UUIDv7.
- `prisma-cli` & `prisma-client-api`: Operações e consultas tipadas no Prisma ORM.
- `prisma-upgrade-v7`: Guia de migração e novos driver adapters do Prisma v7.
- `supabase` & `supabase-postgres-best-practices`: Auth, RLS, Edge Functions e otimização Postgres.

### 3. [Inteligência Artificial Local, Agentes & Automação](local-ai-and-agents.md)
- `graphify`: Memória semântica estrutural em grafos de conhecimento determinísticos (AST).
- `aszadev_agy_offload`: Sidecar local para economia de tokens do Antigravity.
- `laya_decision_engine`: Motor local de triagem rápida e decisões em milissegundos via ONNX.
- `kaggle_cloud_compute`: Orquestrador de computação pesada gratuita em nuvem (GPUs T4 e TPUs).
- `ebook_ai_translator`: Esteira de ingestão e tradução de manuais com reprodução em Mermaid/ASCII.
- `lms_academic_ops`: Automação de tarefas acadêmicas FAT / IFNMG Moodle com Notion Calendar.
